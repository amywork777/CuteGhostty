Built on Ghostty

Cute Ghostty is the same Ghostty you already know and love — just with cute pastel colours, adorable emojis, and a kawaii icon. Under the hood it's 100% Ghostty: the same blazing-fast GPU-accelerated terminal, the same features, the same reliability.

Ghostty is an incredible open-source terminal emulator created by Mitchell Hashimoto. We just made it cuter. The full source is on GitHub — contributions, issues, and stars are all welcome!

Install

Up and running in seconds

Getting Cute Ghostty on your Mac is as easy as downloading, unzipping, and falling in love.

1

Download

Click the download button above. You'll get a disk image file.

CuteGhostty.dmg
2

Unzip & Move

Open the DMG and drag Cute Ghostty into the Applications folder.

Drag → Applications
3

Launch

Double-click to launch and enjoy your new cute terminal. It just works!

open -a "Cute Ghostty"

Requirements

🎀 macOS 13.0+ (Ventura)
🎀 Apple Silicon (arm64)
Or just the config

Already have Ghostty?

Skip the app and make your existing Ghostty cute — themes, the pink icon, and the greeting. Settings (⌘ ,) then opens your cute config.

1

Get Ghostty

Install the real Ghostty if you don't already have it.

brew install --cask ghostty
2

Make it cute

Clone this repo and run the installer — it backs up your config first.

./install.sh
3

Pick a theme

Restart Ghostty and choose any pastel theme in your config.

theme = "Cute Mint"
